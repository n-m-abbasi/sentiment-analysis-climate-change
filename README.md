# Sentiment Analysis of Social Media Users on Climate Change  
### Using Classical Machine Learning & Data Mining Techniques

This project analyzes public sentiment toward climate change using tweets collected from Kaggle.  
The study combines **sentiment analysis**, **semantic clustering**, and **linear regression** to understand how users express emotions about environmental issues.

---

## 📌 Project Overview
This research was originally conducted as an undergraduate project titled:  
**"Sentiment Analysis of Social Media Users on Climate Change Using Classical Machine Learning and Data Mining Algorithms"**

The goal was to explore how classical machine learning methods can reveal emotional and semantic patterns in climate-related discussions.

---

## 🧠 Methods Used

### 1. Data Collection
Tweets were obtained from a Kaggle dataset due to limited access to Twitter API.  
The dataset includes tweet text, timestamps, and basic metadata.

### 2. Preprocessing
- Removing links, mentions, hashtags  
- Lowercasing text  
- Cleaning punctuation  
- TF-IDF vectorization for clustering  
- Preparing raw text for sentiment scoring  

### 3. Sentiment Analysis (TextBlob + VADER)
Sentiment scores were computed using:
- **TextBlob polarity**
- **VADER compound score**

Tweets were categorized into:
- Very Positive  
- Positive  
- Neutral  
- Negative  
- Very Negative

## 📈 Key Results

### 🔹 Sentiment Distribution
Most tweets expressed **negative or very negative** emotions about climate change.  
Positive tweets were mostly educational or motivational.

### 🔹 Semantic Clusters
Three main clusters emerged:

| Cluster | Description | Mean Sentiment |
|--------|-------------|----------------|
| 0 | Negative / crisis-related tweets | -0.09 |
| 1 | Neutral / scientific tweets | 0.09 |
| 2 | Positive / hopeful tweets | 0.11 |

### 🔹 Regression Findings
| Feature | Coefficient |
|--------|-------------|
| Tweet Length | 0.0174 |
| Polarity | 0.6231 |
| Intercept | 0.0217 |
| R² | 0.62 |
